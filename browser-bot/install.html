이카운트 재고봇 설치

Chrome 또는 Edge에서 한 번 설치하면 이카운트에 로그인한 브라우저로 엑셀 13개를 받을 수 있습니다.

  1. 재고관리 ZIP 다운로드 후 압축을 풉니다.
  2. 주소창에 Chrome은 chrome://extensions, Edge는 edge://extensions를 입력합니다.
  3. 개발자 모드를 켜고 압축해제된 확장 프로그램 로드를 눌러 browser-bot 폴더를 선택합니다.
  4. 재고관리 사이트에 다시 접속하고 이카운트 자료 가져오기를 엽니다.

다운로드

  1. 같은 Chrome 또는 Edge에서 이카운트에 로그인하고 ERP 탭 하나를 열어둡니다.
  2. 재고관리 사이트에서 기준일자를 지정하고 이카운트 자동 다운로드를 누릅니다.
  3. 저장된 엑셀을 확인한 뒤 엑셀 파일 직접 선택으로 재고 자료를 불러옵니다.

구글 드라이브에 저장

브라우저 저장 폴더 설정에서 사용할 구글 계정의 데스크톱용 Drive 동기화 폴더를 다운로드 위치로 선택합니다. 이 브라우저에서 받는 다른 파일에도 동일한 위치가 적용됩니다.

파일마다 저장 위치 확인 창이 뜨면 브라우저 다운로드 설정에서 다운로드 전에 각 파일의 저장 위치 확인을 끄거나, 각 파일의 저장 창에서 재고봇이 제시한 이름과 경로를 유지하세요.
