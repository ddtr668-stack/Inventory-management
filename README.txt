재고관리 웹페이지 · GitHub 로그인 판
주식회사 삼성이엔지 아산본사 · 모델별 재고보유 현황 대시보드 (조회 전용)

[어떻게 동작하나]
- index.html 은 로그인 화면만 들어 있습니다. 재고 자료와 대시보드 화면은 data/app.enc 에
  AES-256 으로 잠겨 있어서, 공개 저장소에서 파일을 내려받아도 아이디·비밀번호 없이는 볼 수 없습니다.
- data/keys.json 에는 비밀번호가 아니라 '비밀번호로 잠근 열쇠'만 들어 있습니다 (아이디도 해시로만 저장).
- 로그인은 이 브라우저 탭에서만 유지되고, 탭을 닫거나 '로그아웃'을 누르면 다시 로그인해야 합니다.
- 이카운트 엑셀은 웹 화면의 재고봇으로 받거나 저장된 파일을 직접 선택합니다.

[재고를 최신으로 바꾸려면 (회사 PC)]
1. 회사 서버에서 재고를 반영합니다.
2. github_배포_로그인\만들기\로그인판_만들기.bat 실행 (= python make_pages.py 만들기)
3. github_배포_로그인\올릴파일 의 data/app.enc 를 저장소에 다시 올립니다.

[계정 관리 (회사 PC)]
- 추가 / 비밀번호 변경:  계정추가.bat 실행 (= python make_pages.py 계정추가 아이디)   → 그다음 data/keys.json 다시 올리기
- 삭제:                  python make_pages.py 계정삭제 아이디   → data/keys.json 다시 올리기
- 비밀번호는 8자 이상, 되도록 길게(12자 이상) 정해 주세요. 짧은 비밀번호는 keys.json 을 받아 간 사람이 대입해 볼 수 있습니다.
